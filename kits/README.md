# Off-site execution kits

Everything in this folder is **copy, not code**. Each kit is finished text plus
the field-by-field mapping to the platform it goes into. If you find yourself
writing a sentence, the kit has failed — tell me and I will fix it.

`kits/` sits outside `app/` and `public/`, so Next.js never serves it. None of
this is reachable from the website and none of it is in the sitemap.

---

## The canonical NAP block

**Use this verbatim, character for character, in every listing.** Consistency
across directories is the single largest off-site factor for a practice like
this one, and the usual reason a listing underperforms is a name or URL that
differs by a word or a `www`.

```
Practice name:   Westpeak Wellness
Website:         https://www.westpeakwellness.com
Booking:         https://www.westpeakwellness.com/book
Email:           info@westpeakwellness.com
Service area:    British Columbia, Canada (virtual — all of BC)
Languages:       English, Punjabi
Practitioner:    Aman Bains Dhillon, MA, RCC
Designation:     Registered Clinical Counsellor (RCC), BC Association of
                 Clinical Counsellors
```

**Two rules that matter more than they look:**

1. **"Westpeak Wellness" is one word then one word.** Not "West Peak Wellness".
   The BCACC listing currently has it wrong and that is Kit 2's whole purpose.
2. **Never enter a street address.** This is a fully virtual practice. An
   address you do not see clients at creates a listing that contradicts the
   website, and for a health practice that is the kind of inconsistency that
   suppresses rather than helps.

## No phone number — and what to do when a form demands one

The practice does not take bookings or consultations by phone; everything runs
over secure video. Where a directory makes a phone number mandatory, leave it
blank if the form allows, and otherwise choose the option that routes to email.
Do not invent a number and do not use a personal mobile — a number published in
a directory is a number clients will call, and an unanswered one is worse than
none.

## Compliance, in one line

**Never ask a client for a review or testimonial, on any platform, including
former clients.** BCACC advertising standards prohibit it, because someone in a
therapeutic relationship cannot give uncoerced consent to be used as marketing.
Every kit here is written to that rule. If a platform prompts you to "request
reviews from your clients", ignore it.
